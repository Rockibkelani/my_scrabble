A propos de ce projet

Ce site est servi par server.c, un serveur HTTP minimaliste ecrit en C pur :

  • Sockets POSIX (socket, bind, listen, accept)
  • Un pool de 16 threads (pthread) qui traitent les connexions, joints proprement a l'arret
  • Fichiers statiques servis depuis le dossier public/
  • Routes dynamiques sous /api/* (JSON genere en C)
  • Une API REST complete pour les articles : GET/POST /api/articles, GET/PUT/DELETE /api/articles/:id
  • Un mini-parseur JSON ecrit a la main (aucune bibliotheque externe)
  • Un Scrabble complet dont toute la logique (regles, score, IA, suggestions, dictionnaire de 310 000 mots) tourne cote serveur en C
  • Une gestion memoire tracee : chaque allocation est comptee et l'arret du serveur verifie que tout a ete libere
  • Un formulaire de contact traite cote serveur (POST + decodage URL)
